# C++ Module 00

## Topics
- Namespaces
- Classes
- Member functions
- stdio streams
- Initialization lists
- static, const

## Exercises

### Exercise 00: Megaphone
A simple program that converts input to uppercase.

```bash
cd ex00 && make
./megaphone "hello world"
# Output: HELLO WORLD
```

### Exercise 01: My Awesome PhoneBook
A phonebook application that stores up to 8 contacts.

Commands:
- `ADD`: Add a new contact
- `SEARCH`: Search and display contacts
- `EXIT`: Quit the program

```bash
cd ex01 && make
./phonebook
```

### Exercise 02: The Job Of Your Dreams
Recreate Account.cpp based on Account.hpp header file.
