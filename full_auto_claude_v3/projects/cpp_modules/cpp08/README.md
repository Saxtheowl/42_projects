# CPP Module 08

## Description

CPP Module 08 covers STL containers, iterators, and algorithms.

## Exercises

### ex00 - easyfind
Template function to find an element in any container.

### ex01 - Span
Class to store N integers and find shortest/longest span.

### ex02 - MutantStack
Stack with iterator support by inheriting from std::stack.

## Key Concepts

- **STL Containers**: vector, list, stack, etc.
- **Iterators**: Generic pointers for container traversal
- **STL Algorithms**: find, sort, min_element, max_element

## Compilation

```bash
cd ex00 && make && ./easyfind
cd ex01 && make && ./span
cd ex02 && make && ./mutantstack
```
