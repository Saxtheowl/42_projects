# CPP Module 07

## Description

CPP Module 07 covers C++ templates.

## Exercises

### ex00 - whatever
Template functions: swap, min, max.

### ex01 - iter
Template iter function to apply a function to each element of an array.

### ex02 - Array
Template Array class with bounds checking.

## Key Concepts

- **Function templates**: Generic functions that work with any type
- **Class templates**: Generic classes parameterized by type

## Compilation

```bash
cd ex00 && make && ./whatever
cd ex01 && make && ./iter
cd ex02 && make && ./array
```
