# Bomberman - Classic Arcade Game

Terminal-based Bomberman implementation.

## Features

- Destructible blocks
- Multiple enemies
- Bomb chain reactions
- Power-ups (more bombs, bigger explosions)
- Score tracking

## Usage

```bash
python bomberman.py        # Play game
python bomberman.py --demo # Watch demo
```

## Controls

| Key | Action |
|-----|--------|
| W/↑ | Move up |
| S/↓ | Move down |
| A/← | Move left |
| D/→ | Move right |
| Space | Place bomb |
| Q | Quit |

## Symbols

- `P` - Player
- `E` - Enemy
- `#` - Wall (indestructible)
- `X` - Block (destructible)
- `1-3` - Bomb (timer)
- `*` - Explosion
- `b` - Bomb power-up
- `p` - Power power-up
