# Piscine Go - Go Language Basics

Collection of Go exercises from 42's Go Piscine.

## Features

### Number Functions
- `PrintAlphabet` - Print a-z
- `PrintReverseAlphabet` - Print z-a
- `PrintDigits` - Print 0-9
- `IsNegative` - Check if negative
- `PrintComb` - Print 3-digit combinations
- `IterativeFactorial` / `RecursiveFactorial`
- `IterativePower` / `RecursivePower`
- `Sqrt` - Integer square root
- `IsPrime` - Primality test
- `FindNextPrime` - Find next prime
- `Fibonacci` - Fibonacci number

### String Functions
- `StrLen` - String length
- `StrComp` - String comparison
- `StrReverse` - Reverse string
- `ToLower` / `ToUpper` - Case conversion
- `Capitalize` - Capitalize words
- `IsAlpha` / `IsNumeric` / `IsAlphaNumeric`
- `Split` / `Join`
- `Atoi` / `Itoa`

### Slice Functions
- `SortIntSlice` / `SortStringSlice`
- `Map` - Apply function to slice
- `Filter` - Filter elements
- `Reduce` - Reduce to single value
- `Any` / `All` - Predicates

## Usage

```bash
# Run demo
go run main.go demo

# Build
go build -o piscine_go main.go
./piscine_go demo
```
