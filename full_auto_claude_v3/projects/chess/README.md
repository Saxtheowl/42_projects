# Chess

Chess engine with AI opponent using Minimax with Alpha-Beta pruning.

## Features

- Full chess rules (moves, captures, pawn promotion)
- Unicode piece display
- Minimax AI with alpha-beta pruning
- Position evaluation
- Human vs AI gameplay

## Usage

```bash
./chess.py
```

## Controls

Enter moves in algebraic notation: `e2e4` (from e2 to e4)
Type `quit` to exit.

## AI Algorithm

- Minimax search with alpha-beta pruning
- Depth 3 by default
- Material evaluation with positional bonuses
