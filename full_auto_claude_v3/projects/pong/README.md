# Pong - Classic Arcade Game

Terminal-based Pong implementation.

## Features

- Single player vs AI
- Ball physics with spin
- Speed increases on paddle hits
- Score tracking
- First to 5 wins

## Usage

```bash
# Play game
python pong.py

# Watch demo
python pong.py --demo
```

## Controls

| Key | Action |
|-----|--------|
| W/↑ | Move paddle up |
| S/↓ | Move paddle down |
| Q | Quit |
