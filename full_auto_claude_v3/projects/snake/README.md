# Snake - Classic Snake Game

Terminal-based snake game.

## Features

- Classic snake gameplay
- Wrap-around walls
- Growing snake on food
- Score tracking
- Speed increases with score
- Restart functionality

## Usage

```bash
# Play game
python snake.py

# Watch demo
python snake.py --demo
```

## Controls

| Key | Action |
|-----|--------|
| W/↑ | Move up |
| S/↓ | Move down |
| A/← | Move left |
| D/→ | Move right |
| R | Restart |
| Q | Quit |

## Game Rules

- Collect food (●) to grow and score points
- Don't hit yourself
- Walls wrap around (pacman style)
- Speed increases with score
