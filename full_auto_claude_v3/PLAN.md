## HOW TO TEST

Each project has a README with testing instructions:

```bash
# Python projects
python3 project/main.py

# C projects
cd project && make && ./project

# C++ projects
cd project && make && ./project

# Assembly projects
cd project && make && ./test_program

# Web projects
python3 project/server.py  # then open browser

# Documentation-only projects
cat project/README.md
```

All C/C++ projects compile with `-Wall -Wextra -Werror`.
