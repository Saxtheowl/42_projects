# Usage local (recap)

Commandes rapides :

1) Initialiser .env (optionnel) :
```bash
./scripts/setup_env.sh
./scripts/load_env.sh
```

2) Lancer un check global :
```bash
./scripts/doctor.sh
```

3) Smoke test complet :
```bash
./scripts/smoke_local.sh
```

4) Test routing matrix :
```bash
./scripts/test_routing_matrix.sh
```

5) Generation PDF dummy :
```bash
./scripts/generate_dummy_pdf.py
```

6) Sommaire README :
```bash
./scripts/readme_toc.sh
```
