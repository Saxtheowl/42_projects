# RMSE plot helper

`ft_linear_regression` relies on the helper script `C/ft_helpme/scripts/reports/rmse_plot.py` to summarize the training history stored in `data/history.json`. It produces:

- `plots/latest_rmse.txt` (ASCII sparkline + summary metrics)
- `plots/latest_rmse.png` (optional PNG when `matplotlib` is installed)

## Usage

Train normally with the wrapper:
```bash
./scripts/train.sh --learning-rate 0.1 --iterations 1000 --scheduler exponential --decay 0.95
```

Or run the helper directly:
```bash
python3 C/ft_helpme/scripts/reports/rmse_plot.py data/history.json --png plots/latest_rmse.png > plots/latest_rmse.txt 2>&1
```

## Notes

- The helper reads the JSON generated by `src/train.py --history data/history.json`.
- The PNG is optional; the text file always captures the summary even without `matplotlib`.
